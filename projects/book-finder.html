Ex 10: Book Explorer via jQuery $.ajax
jQuery 3.7.1 • AJAX GET

Hypothetical Book API & jQuery $.ajax

CSCA 514 Lab 10: Clicking "Load Books" sends a jQuery Ajax GET request to a simulated book API endpoint (`https://api.example.com/books`), parses the JSON response, and renders book front covers, titles, authors, and metadata.

API Endpoint:

Executing `$.ajax({ method: 'GET', url: 'https://api.example.com/books' })`...

// jQuery Ajax Implementation for Exercise 10
$('#btn-load-books').on('click', function() {
    var endpoint = $('#api-endpoint').val();
    
    // Asynchronous GET request using jQuery's $.ajax method
    $.ajax({
        url: endpoint,
        type: 'GET',
        dataType: 'json',
        beforeSend: function() {
            $('#ajax-loader').show();
            $('#books-container').empty();
        },
        success: function(response) {
            $('#ajax-loader').hide();
            // Parse JSON response and display books (titles and authors)
            renderBookCards(response.books);
        },
        error: function(xhr, status, error) {
            $('#ajax-loader').hide();
            console.error("Ajax Error: " + error);
        }
    });
});
